# 把「今晚写三条脚本」从加班项里拿掉：skill-video-script 给营销团队的发布说明

周二晚上九点，防晒还没拍。运营打开备忘录，第一句写了又删：要停滑，又不能喊麦；要讲 SPF，又不能把视频号讲成说明书。编导在群里问「分镜有了没」，投放说「三条 A/B 明天中午前要」。这不是缺少灵感，是缺少一份**今天能拍**的结构。

[skill-video-script](https://github.com/samjia12/skill-video-script) 把这件事收成一次输入。你提供产品名、卖点和平台（抖音 / 视频号 / B 站），它固定输出三版风格：种草安利、干货教程、剧情反转。每一版带分镜表、带时间码的口播、黄金 3 秒、BGM 曲库搜索词和字幕规范。默认引擎离线、不用密钥；Agent 读 `SKILL.md` 也能跑同一条命令。

## 一个真实周的前后对比

以仓库里的防晒霜示例为原型，想象一个三人小组的周更。

**以前。** 周一选题会 40 分钟，确定卖点「清爽、SPF50+、学生价」。周一到周二，文案写一版种草，编导再拆分镜，平均 **2.5 小时**。周三临时说「视频号也要」，又改语气、改 CTA，再 **1 小时**。周四才想起干货和反转没做，又各 **45 分钟**。三平台 × 还不算对齐字幕和 BGM，一周轻松 **6–8 小时** 耗在「从空白到可拍」。拍的时候黄金 3 秒仍然含糊，完播靠运气。

**现在。** brief 写成 JSON（或命令行三个参数），本机几秒出九份骨架（3 风格；换平台再跑两次）。人的工作变成：**选一版、改两句、对表拍**。实测命令：

```bash
python3 scripts/generate_script.py examples/douyin_skincare.json
```

从打开仓库到拿到带时间码的口播，**不超过 5 分钟**（含读 README）。若团队每周做 6 条短视频，按「每条结构 50 分钟 → 8 分钟」粗算，一周收回约 **4 小时**。这 4 小时可以去对完播数据，而不是改第一句。

数字不是实验室神话，是工时结构变了：生成器不替代出镜，它替代「从零发明分镜语法」。

## 三个场景故事

**电商运营。** SKU 轮换快。今天防晒，明天胶囊咖啡机。以前每条都从「大家好我发现了」开始，平台一换，口播还是抖音味。现在视频号示例会把 CTA 推向关注和私信，而不是小黄车；B 站示例带开箱/测评话题和更长时长。运营只维护 brief 里的卖点清单，避免口播发明 brief 没有的功效。

**品牌社媒。** 要的不是更多金句，是 A/B。同样的卖点，结果前置、目录感、还是打脸反转，完播差一截。三版脚本是现成实验组。先看哪一种黄金 3 秒留人，再把投放压到赢的形状——雷达图在 [demo](../../demo/index.html) 和 [样例报告](../../examples/report-sample/report-sample.md) 里可以直接给策划看。

**MCN 与一人团队。** 没有专职编导时，Agent 按 Skill 收字段、跑 CLI、按固定顺序交出三稿。人负责选稿和出镜。一人创作者对着时间码念，不必先学「分镜表怎么画」。

## 上手四步

1. 克隆 https://github.com/samjia12/skill-video-script ，Python 3.9+，`pip install -r requirements.txt`（测试用 pytest；生成脚本本身只需标准库）。  
2. 复制 `examples/douyin_skincare.json`，改 `name` / `selling_points` / `platform`。  
3. `python3 scripts/generate_script.py your.json -o output/script.md`。  
4. 把 Markdown 丢给编导或提词器。浏览器里可打开 `demo/index.html` 做给业务看的走查。

架构上，模板管线在前、LLM 在侧。系统怎么拆、失败码怎么走，见 [docs/architecture.md](../architecture.md) 的流程图与时序图：校验失败不会产出半成品；LLM 只许改口播和标题，不许改时间轴。这是给剪辑同学的承诺：表上的 0.0–3.0 秒永远是黄金 3 秒。

## 它不替你做的事

它不成片、不配乐文件、不上传。口播是中文。`tiktok` 别名走抖音 playbook，不是欧美 TikTok 规则。默认文案是确定性模板，要更像即兴再开 `--backend llm`。法律审核仍然要看 brief：工具拒绝编造未提供的疗效。

## brief 怎么写才拍得动

生成器不是许愿池。字段越具体，黄金 3 秒越不像空喊。最低要有名称、平台、至少一条卖点。建议补上人群、价格、品类：演示里的「79 元」「学生党」会直接进钩子和话题。时长可以空着，引擎会落到平台甜区（抖音约 27 秒、视频号约 36 秒、B 站约 60 秒）；填了非法数字会直接报错，不会默默拍一条 5 秒广告。

样例报告把九份脚本摊成柱状、折线、饼图、雷达和热力，用来回答「本周先拍谁」。它不替代完播后台，但能在开拍前把结构争论停在会议上：字数热力已经显示抖音约 200 字、B 站约 300 字，再往口播里塞参数，是和字速作对。

对营销团队，发布日的意义很具体：把「今晚写三条脚本」从加班项里拿掉，把时间还给拍摄和复盘。仓库 MIT 开源，Issue / PR 模板已经开好。下一步是把你自己的 SKU 填进 JSON，而不是再开一轮头脑风暴。
