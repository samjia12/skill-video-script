# skill-video-script v0.1.0

First public release. Date: 2026-08-23.

Open-source Agent Skill and CLI that turns a product brief into **three short-video scripts** for Douyin, WeChat Channels, and Bilibili.

Repository: https://github.com/samjia12/skill-video-script

## Highlights

- Offline by default (Python 3.9+, standard library). No API key required.
- Always 3 styles: 种草安利 / 干货教程 / 剧情反转.
- Each style includes storyboard, timed voiceover, golden 3-second hook, BGM library keywords, and subtitle spec.
- Optional OpenAI-compatible LLM rewrite (`--backend llm`) that fails closed without `VIDEO_SCRIPT_API_KEY`.

## Features

- **Platforms:** `douyin` / `wechat` / `bilibili` (aliases 抖音, 视频号, B站, and a few English spellings).
- **CLI:** `python3 scripts/generate_script.py` from a JSON file, flags, or stdin (`-`).
- **Outputs:** Markdown, JSON, or both (`--format md|json|both`).
- **Library:** `parse_brief`, `generate`, `render_markdown`, `render_json` (`PYTHONPATH=src`).
- **Agent Skill:** `SKILL.md` with trigger phrases and a fixed presentation order.
- **Safety:** sanitizes control / bidi / zero-width characters; escapes Markdown; refuses unlicensed track titles.
- **Tests:** unit coverage for core functions plus eight boundary classes (empty, oversized, illegal JSON, network, rate limit, concurrency, special characters, access denied).

## Install

```bash
git clone https://github.com/samjia12/skill-video-script.git
cd skill-video-script
python3 -m pip install -r requirements.txt
python3 scripts/generate_script.py examples/douyin_skincare.json
python3 -m pytest tests
```

## Known limitations

- Spoken copy is **Chinese only**. `--language en` records the brief language; it does not switch the voiceover.
- Platforms are Douyin, WeChat Channels, and Bilibili. The `tiktok` alias maps to the **Douyin** playbook (China market), not TikTok US/EU rules.
- Default engine is template/strategy based. Variety is deterministic; it will not improvise like a large model unless `--backend llm` is on and configured.
- LLM rewrite is best-effort: timings, storyboard spans, BGM, and hashtags stay on the template result if the model JSON is unusable.
- This tool does **not** render video, generate audio, or upload to a platform. BGM output is search keywords, not an audio file.
- Hard caps: product name ≤ 80 characters, ≤ 12 selling points, duration 8–180 s (then clamped to the platform sweet spot), total payload ≤ 8000 characters.
- Hook lines prefer a complete sentence that fits ~3 seconds. A long product name may appear in later shots rather than in the opening.

## Roadmap

These are intentions, not commitments. Open an issue to vote or help.

1. **More surfaces:** first-class playbooks for TikTok, YouTube Shorts, and Instagram Reels (music licensing and CTA differ).
2. **English (and bilingual) voiceover** when `--language en` is set.
3. **Brand voice packs:** extra style files per brand without forking `copy_bank.py`.
4. **Stricter LLM schema:** keep enhancement only when every shot timing still validates.
5. **Export helpers:** shot list as CSV / Premiere markers; optional storyboard stills (out of scope for the core generator).
6. **Packaging:** `pip install skill-video-script` with the `video-script` console script, so `PYTHONPATH=src` is no longer required.
