## LinkedIn (English)

Short-form video is the shelf, not a side channel. The same SKU still has to stop the scroll on Douyin, sound like a friend’s tip on WeChat Channels, and carry real information density on Bilibili.

We open-sourced skill-video-script (MIT): an Agent Skill and a Python CLI that turns a product brief into three filmable scripts — recommendation, how-to, and story twist. Each version includes a timed storyboard, a teleprompter voiceover, a golden three-second hook, licensed-library BGM keywords, and subtitle rules. The default engine is offline. No API key.

On a weekly cadence, the expensive part is not the punch line. It is inventing storyboard grammar from a blank page (often 45–60 minutes per cut, before anyone shoots). The CLI returns three skeletons in seconds so editors pick a version, change two lines, and shoot to the table.

If you run ecommerce content, brand social A/B tests, or a small MCN desk, the repo, demo, and a sample analytics packet are here:

https://github.com/samjia12/skill-video-script
