# 三小时产能，压到三分钟：营销人为什么需要 skill-video-script

短视频已经不是「再加一条内容」，而是货架本身。同一款产品，要在抖音完成停滑，要在视频号听起来像朋友推荐，要在 B 站把参数和章节讲清楚——结构不同，节奏不同，结尾的行动指令也不同。多数团队真正缺的不是灵感，而是一份今天就能对着拍的分镜。

[skill-video-script](https://github.com/samjia12/skill-video-script) 是给营销、运营和内容团队用的开源工具。你提供产品名、卖点和目标平台，它一次生成三版风格完全不同的短视频脚本：**种草安利、干货教程、剧情反转**。每一版都带分镜表、带时间码的口播、黄金 3 秒开头、BGM 曲库搜索词，以及字幕的字体、位置和高亮色。它既是 Agent 可以加载的 Skill，也可以在没有大模型密钥的电脑上，用一条命令跑完。

## 四个真实使用场景

**电商运营赶周更。** 防晒、小家电、外设轮着上，不能每条都从空白页开始。把 brief 丢进工具，先拿到可拍结构，再决定今天拍种草还是拍教程。人的时间留给出镜和选品，而不是重写第一句。

**品牌社媒做开头实验。** 同样的卖点，用结果前置、好奇缺口还是模式打断，完播会差一截。三版脚本就是现成的 A/B 素材：先看哪一种黄金 3 秒更能留人，再把投放压到赢的那条。

**MCN 和小团队把流程交给 Agent。** 人负责选稿、合规和出镜；Agent 按 `SKILL.md` 收齐字段、调用生成器、按固定顺序交出三稿。减少「再帮我写一条抖音」这种从零聊天。

**个人创作者没有编导。** 需要的是能对着镜头念、对着分镜拍的东西，而不是一段无法落地的感觉文案。口播带时间码，字幕有行宽，BGM 只给授权曲库的搜索词，版权边界清楚。

## 收益不在「句子更炫」

第一是**时间**。默认引擎离线、确定、几秒出三稿，把「想结构」从「抠金句」里拆开。没有 API Key 也能用。

第二是**平台差异被写进规则**。抖音默认约 27 秒、快切、购物车话术；视频号更克制，CTA 偏关注和私信；B 站更长，给弹幕留顶、鼓励三连。这不是换一组话题标签那么简单。

第三是**可协作、可对照**。Markdown 给编导粘贴，JSON 接下游工具。同一份 brief 两次生成一致，方便评审和回归，而不是每次模型心情不同。

第四是**少踩版权和夸张承诺**。BGM 只输出情绪、BPM 和曲库关键词，不点名热歌。口播也不替你编造 brief 里没有的疗效或收益。

## 它不是什么

它不是成片工具，不会替你出镜、剪辑或上传。默认模板有文案上限；若要更像即兴口语，可以再开可选的 LLM 润色，但没有密钥时主路径仍然可用。目前口播面向中文场，覆盖抖音、视频号和 B 站，不含 TikTok / Shorts / Reels 的完整 playbook。

对营销团队，值钱的是**今天能开拍**，而不是再开一轮头脑风暴。克隆仓库后运行：

```bash
python3 scripts/generate_script.py examples/douyin_skincare.json
```

即可看到完整三版。文档与示例见仓库 README。
